Virtual Driving School 1.0.0
============================

This installer is for 64-bit Windows 10 or later, including low-end PCs.

After setup you can launch Virtual Driving School from the Start menu.
Press F10 in the game to switch between Low (default) and High graphics.

Controller support
------------------
A Logitech G920 steering wheel and pedals are optional. Keyboard and
gamepad also work. If you use a Logitech wheel, install Logitech G HUB
from Logitech's website so Windows can see the wheel and pedals, then
run the in-game calibration wizard.

The installer is not code-signed, so Windows SmartScreen may show a
warning. Choose "More info", then "Run anyway" if you trust this build.
